# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Please do not publish exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature under **Security → Advisories → Report a vulnerability** when available. If private reporting is unavailable, contact the maintainer through the email listed on the GitHub profile and include:

- A concise description
- Affected version or commit
- Reproduction steps
- Expected impact
- A suggested mitigation, if known

Remove credentials, personal information, and sensitive telemetry before sharing evidence.

## Project scope

BLACKTERM // MITRE Mapper is intended for authorized defensive telemetry analysis. Reports about features used outside that scope may be closed without action.
